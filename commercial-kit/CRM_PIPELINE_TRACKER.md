# Jiseek CRM / Pipeline Tracker

Purpose: keep the commercial system simple enough to operate personally while making pipeline visible and measurable.

Use a spreadsheet, Notion database or lightweight CRM. Do not over-engineer the system before the first S$200k–300k of validated revenue.

## Core Fields

| Field | Purpose |
| --- | --- |
| Account | Organisation name |
| Segment | Public sector / Infrastructure / Education / Professional services / SME / Association / Other |
| Contact | Decision-maker or key influencer |
| Role | CEO / COO / CIO / CHRO / HOD / Transformation / Other |
| Relationship | Warm / Referral / Cold / Existing client / Past client |
| Trigger / Problem | Why this account may need Jiseek now |
| Current AI maturity | Curious / Experimenting / Piloting / Implementing / Scaling |
| Opportunity | Briefing / Diagnostic / Sprint / Programme / Advisory / Academy |
| Estimated value | Expected contract value |
| Probability | 10 / 25 / 50 / 75 / 90% |
| Weighted pipeline | Estimated value × probability |
| Stage | See stages below |
| Last contact | Most recent interaction |
| Next action | Specific next commercial action |
| Next action date | Date it must happen |
| Sponsor strength | Low / Medium / High |
| Timing | Now / 30 days / 90 days / Later |
| Notes | Context, objections, buying process |

## Pipeline Stages

### 0 — Target
Account identified but no meaningful engagement yet.

### 1 — Contacted
Personal outreach sent or introduction requested.

### 2 — Conversation
Initial conversation scheduled or completed.

### 3 — Qualified
Material problem, sponsor, timing and credible buying potential identified.

### 4 — Scope
Engagement scope being shaped with client.

### 5 — Proposal
Commercial proposal issued.

### 6 — Verbal / Procurement
Client intends to proceed; contracting / procurement underway.

### 7 — Won
Signed / purchase order / formal confirmation received.

### 8 — Lost / Nurture
Not proceeding now. Record reason and future trigger.

## Probability Guide

- Target: 5%
- Contacted: 10%
- Conversation: 20%
- Qualified: 35%
- Scope: 50%
- Proposal: 65%
- Verbal / Procurement: 85%
- Won: 100%

Use judgement rather than treating these percentages as accounting truth.

## Dashboard Metrics

Review weekly:
- total qualified pipeline
- weighted pipeline
- number of qualified opportunities
- proposal value outstanding
- average proposed contract value
- win rate
- contracted revenue this month
- collected cash this month
- average days from first conversation to signed engagement
- expansion pipeline from existing clients

## Operating Rule

No qualified opportunity may sit without a dated **next action**.

If a deal has no next action, it is not being actively sold.
